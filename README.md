# Telegram Bot Arianto

### Community Moderation & Automation Bot

A Telegram bot project focused on practical community automation, including moderation workflows, spam handling, and link management.

## ✨ Capabilities

- Community moderation automation
- Spam / flood handling
- Link-sharing controls
- Join and welcome workflows
- Message handling utilities
- Configurable moderation behavior

## 🧰 Focus Areas

**Telegram Bot API · Automation · Moderation · Event Handling · Backend Development**

## 🚀 Project Purpose

This project is a practical exploration of building reliable automation for an active Telegram community. The emphasis is on clear rules, predictable behavior, and reducing repetitive moderation work.
